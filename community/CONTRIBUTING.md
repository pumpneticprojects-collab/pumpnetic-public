# Contributing to Pumpnetic

Thank you for your interest in contributing to the Pumpnetic public repository.

This is a public documentation and assets repository. Contributions that improve accuracy, clarity, or completeness are welcome.

---

## What You Can Contribute

- **Documentation fixes** — typos, broken links, outdated information
- **Translation** — community translations of project documentation
- **Asset improvements** — higher-quality or additional format assets (following the existing naming standard)
- **Community content** — meme templates, campaign assets (must align with project narrative)

---

## What Belongs Here vs. Elsewhere

| Type | Where |
|---|---|
| Documentation, assets, legal | This repo (`pumpnetic-public`) |
| Smart contract source code | Separate audited contract repo |
| Website code | Project-specific repos |
| Community discussions | Telegram / X |

---

## How to Contribute

1. **Fork** this repository
2. **Create a branch** with a descriptive name: `fix/nsgc-broken-link`, `docs/add-noalc-translation`
3. **Make your changes** — keep them focused and minimal
4. **Open a Pull Request** with a clear description of what you changed and why
5. A maintainer will review and merge or provide feedback

---

## Commit Style

We use semantic commits:

```
docs(nsgc): fix broken BSCScan link
fix(assets): replace incorrect noalc logo
feat(docs): add NOALC Spanish translation
chore(legal): update disclaimer date to 2026
```

Format: `type(scope): short description`

| Type | Use for |
|---|---|
| `feat` | New content or files |
| `fix` | Corrections to existing content |
| `docs` | Documentation-only changes |
| `chore` | Maintenance, metadata, housekeeping |
| `refactor` | Structural improvements without content changes |

---

## Standards

- All documentation is written in English (primary)
- Markdown formatting follows existing file conventions
- All links must be verified before submitting
- Contract addresses must be verified against on-chain data before inclusion
- No promotional, affiliate, or third-party commercial content
